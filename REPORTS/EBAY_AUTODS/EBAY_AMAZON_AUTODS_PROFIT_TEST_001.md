## F. Kill / Fix / Scale Rules
- **Kill** if 0 impressions after 3–4 days, or net margin proven negative. **Fix title/SEO** if impressions low.
- **Fix price** if views but no watchers. **Fix offer/bundle** if watchers but no sales.
- **Scale** ONLY if net profit positive AND account-health clean. **Never scale** if late-shipment/cancellation/return/defect risk rises.
