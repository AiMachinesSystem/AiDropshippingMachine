# 00_SYSTEM_CONTROL — governo della macchina

Sala macchine: costituzione, stato, memoria, cockpit, protocolli, template e missioni.

## File chiave
- **VISION_ALIGNMENT.md** — costituzione owner-maintained (identità, North Star, asset map, hard rules).
- **VISION_SCHEMA.md** — stack target della macchina (layer, ordine di implementazione).
- **VISION_GAP_MATRIX.md** — stato vs schema, col criterio di punteggio invariato.
- **RESEARCH_MEMORY_INDEX.md** — memoria interrogabile dei run (QUERY MODE; regola numeri canonici).
- **MACHINE_STATE.md** — stato sintetico (skill, strumenti, integrazioni, fasi progetto).
- **BACKLOG.md** / **NEXT_ACTIONS.md** — item aperti e prossime azioni.
- **MASTER_DASHBOARD.md** — cockpit unico (refreshato a ogni fine run).
- **ERROR_REGISTRY.md** — errori → regole → regression (parte vuoto).
- **SESSION_START_PROTOCOL_v0.1.md** — primo atto di ogni sessione autonoma.
- **VAULT_CONVENTIONS.md** — nomi, cartelle, muri noti, cache, numeri canonici.

## Cartelle
- **TEMPLATES\** — modelli di output (schema §8, launch pack).
- **PLAYBOOKS\** — schede strumenti (jina, playwright, n8n) + n8n_workflows\.
- **BASES\** — viste Obsidian (backlog, decisioni, report).
- **MISSION_TEMPLATES\** — scheletri di missione (AUTONOMOUS_MISSION_TEMPLATE).
- **TASKS\** / **DECISIONS\** — note atomiche di task e decisioni (alimentano le Bases).
