# PLAYBOOK — Graph/Graphify per Obsidian (classe C — istruzioni per l'owner)

**Gap:** Layer 4 (comprensione semantica). L'install passa dall'app Obsidian
(GUI) → non eseguibile dalla macchina; ~10 min owner.

1. Obsidian → Settings → **Core plugins → Graph view**: attivare (zero
   install, già incluso) — primo passo gratuito che copre l'80% del bisogno.
2. Per il graph avanzato in stile "Graphify": Settings → Community plugins →
   Browse → cercare/valutare un plugin graph mantenuto (es. classe
   "Extended/Juggl-like"); criteri: aggiornato di recente, repo pubblico,
   nessun servizio cloud richiesto.
3. Precondizione che la macchina può preparare da sola (classe A, già in
   parte fatta): più backlink `[[...]]` nei file portanti — indice ↔ report ↔
   decision log — perché il graph è utile solo quanto i link che trova.
4. Dopo l'attivazione: test con le domande dello schema ("quali file
   definiscono il GO Gate?", "quale decisione deriva da quale ricerca?") e
   eventuale `GRAPHIFY_READINESS_REPORT.md`.

Nessuna azione eseguita stanotte: decisione e install = owner.
