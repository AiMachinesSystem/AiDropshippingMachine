# 09_TEMPLATES

**Purpose:** Reusable starting points.

This folder holds blank templates and standard formats used throughout the
system — for analyses, strategy briefs, execution plans, reports, and reviews.
Using shared templates keeps work consistent and fast to produce.

When you start a new note in any other folder, copy the matching template from
here rather than starting from scratch.

**Typical contents**
- Note and document templates
- Standard report and brief formats
- Checklists and recurring frameworks
- Naming and structure conventions
